SecondWave is a pump.fun replay trading bot that never snipes the create slot. It tapes every launch from its CreateEvent and buys only after strangers have put real SOL behind a coin, the recent tape is dominated by buys, the creator has not sold, and the price is pressing its highs; it then rides winners with a trailing stop and cuts positions fast when the creator sells, flow dies, or distribution starts. It is a pure function of the batches it is fed — no clock, no randomness, no I/O — so the harness's two executions agree byte for byte.

## Run it

```sh
node main.ts
```
